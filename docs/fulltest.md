### 이번에 찾아서 고친 것
- 3화: 연이 정이 선택과 상관없이 +1 되던 줄을 지움.
- 9화: 몸 문구 조건이 맞지 않아 늘 안 나오던 것을 `v2_hp<=10`으로 고침(다친 길에서 14→8로 나오는 것 확인).
- 7화: 「못 본 척 지나간다」 선택지가 빠져 닿지 않던 갈래 하나를 이음.
- 스탯 띠: 이전보다 안 예쁘다는 말에 다시 그림 — 위줄 「N화 제목」 + 오른쪽 흑호방 빚 칩과 붉은 「그믐 D-n」 도장(이틀 이하에서 숨쉬듯), 아래줄 몸·기억(「초식」 틀)·동전. 바뀔 때 띠 아래에 색 줄 알림.
- 레포↔PC 대조(파일 106개): 수치 띠 윗줄 「N화 제목」을 넣은 판이 PC에 안 올라가 있어 윗줄이 비어 있었다 → 올리고 1화에서 「1화 이백 동」이 뜨는 것 확인. 나머지 105개 일치.
- 기본 소리 크기 절반(기존 저장값도 한 번 반으로).
- 초상 9인(곽두·하후연·진우·연이·마철구·탁진·백야·단목천·석운): 옆이 잘리거나 아래가 떠 보이던 것을 판 안 70%로 줄여 앉히고 몸을 화면 아래까지 이어 그린 뒤, 이어 붙인 자리의 가로 줄을 다시 칠해 지움. 배경은 isnet-anime로 다시 땀(회색 네모 찌꺼기 없앰). 석운도 같은 기준(0.70/120)으로 맞춤.
- 원고(story-v2 00~10)를 게임 대본에서 다시 뽑아 맞춤.
