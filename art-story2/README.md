# 새 이야기 인물 초상 (1판)

- 방식: 「장면1」 — Animagine XL 4.0 + molak_style_v1-000008(0.7), 인물마다 제 배경·옷으로 장면을 그린 뒤 BiRefNet으로 누끼.
- 크기 832×1216, 투명 PNG.
- 이름: char_<인물>.png(기본), char_<인물>_smile / _angry / _sad.png
- 인물: dan(단목천) jinu(진우) gwakdu(곽두) yeoni(연이) seokun(사부 석운) baekya(백야) hahuyeon(하후연) macheolgu(마철구)
- 소아는 기존 게임 초상(unity-art-v23/char_soa*.png)을 그대로 쓴다.
- 남은 손볼 곳: 단목천 머리 왼쪽 흰 빛 조각, 연이 왼쪽 가장자리 흰 조각.
