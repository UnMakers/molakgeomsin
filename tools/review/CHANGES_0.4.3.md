# 몰락검신 0.4.3 — 바뀐 것

**0.4.17** (빌드 43, 1649MB, 오류 0, Drive `몰락검신_v0.4.17.apk`): 죽음 엔딩 보강, 종장 앞 새 장 「북행(北行)」, 새 장면 그림 3장.
- 죽음 엔딩(MolakOver): 사술 폭주·탈진·아사·비무 패배·야습·원수·빚·자객·협·생사결·독·곪은 상처 서술을 두세 배로 늘렸다(상복 입은 아우, 왕삼 수하 셋, 횟가루 금, 금창약을 아낀 상처 등).
  - 「마지막 얼굴」: 숨이 끊기기 전 이번 생에 쌓은 인연 하나가 떠오른다(소아의 지붕 / 암향의 손목 / 청묘의 대추 / 하진무의 주판 / 곽산의 짠 국 / 용개의 지게). 야습 죽음은 지게꾼 일곱이 불길에 물을 나르는 줄이 따로 있다.
  - 회귀 아침이 죽은 까닭에 따라 갈린다(문양이 식은 척 / 굶지 않은 몸 / 흰 손톱 / 그을림 없는 서까래 / 쌍검 자리 / 아직 아무도 모르는 이름 / 놓친 손). 회귀 10회부터 한 줄 더.
- 새 장 「북행(北行)」(Molak14, 떠나기 전 밤 다음 → 혈마곡 어귀): 검은 산까지 닷새.
  - 첫날 새벽 나루: 하진무의 「방값 거스름」 꾸러미. 용개가 직접 삿대를 잡는다(회목채 일곱). 없으면 사공에게 삯을 치르거나 삿대를 대신 젓는다.
  - 둘째 날 북령 관문: 곽산이 창으로 목책을 열고 고개에 남는다("돌아오는 길에 이 고개를 누가 막고 있으면 곤란하잖냐"). 없으면 칼집째 지나간다〔검술+1〕/ 짐승 길 / 죽은 교도의 통행패.
  - 셋째 날 모닥불: 소아와 마주 앉는 밤(외눈의 내력 / 칼끝 맞추기 / 장작 하나 더), 암향의 침향과 쪽지, 청묘의 대추와 틀린 경 한 줄, 혼자면 노인의 목소리.
  - 넷째 날 빈 마을: 우물가 노파. 교가 젊은이들을 '그릇'으로 데려갔다. 육포를 나눈다 / 묻는다(대전 밑 → 교주 대전에서 한 줄) / 두레박을 길어 준다(능선의 늙은이). 사당의 두 번째 손님을 본 생이면 능선 위에 복면 벗은 노인이 서 있다.
  - 다섯째 날: 소아와 나란히 걷는 발소리.
- 귀향길(에필로그): 북행을 거친 생이면 돌아오는 엿새 길이 붙는다. 우물가 노파와 전각 밑에서 나온 아이들, 북령 목책 밑에서 졸던 곽산("국 식겠다. 가자"), 맨 앞 배의 용개.
- 「거꾸로 꽂힌 창」(곽산의 아내가 죽은 날) 갈래 셋: 창을 뽑아 초가로 가져간다(빈 부엌, 곽산이 끓이는 짠 국) / 창 앞에 술 한 잔(저녁엔 잔이 일곱) / 지나친다.
- 곽산의 아내가 죽은 생이면 북령 관문과 「마지막 얼굴」의 곽산 대사가 그에 맞게 바뀐다.
- 새 장면 그림 3장(ComfyUI, 원본 `unity-art-v11/`, 후처리 `tools/post_art_v11.py` — 붉은 강조가 위쪽에 있어도 지워지지 않게 낙관 제거를 좌우 띠로 한정): 북령 고개(scene_pass, 붉은 깃발), 바위 그늘 모닥불(scene_camp), 빈 마을 우물(scene_village).

  - 용개×암향 「나루의 보따리」: 떠날 배를 준비하는 암향. 지게꾼들이 보따리를 숨긴다.
  - 할멈×청묘 「반 알의 셈」: 사부의 반 알을 막내 손에 쥐여 준 사람이 청묘였다.
  - 소아×진백 「늑대의 이름」: 혈랑대주가 대사형이란 걸 안 소아. 막는다 / 같이 사당에 간다(쌀자루와 짚신) / 청묘를 살린 값이었다고 말한다.
  - 곽산×소아 「창과 쌍검」: 아내 약값을 건 백 합. 소아가 이기고 약값을 낸다.
  - 노인×소아 「적운에도 온 노인」: 십 년 전 적운 산문에서도 같은 노인이 아이 하나를 내놓으라 했다. 그 아이는 우물에 들어갔다.
  - 하진무×암향 「고치지 않은 빗장」: 창틀로 드나드는 손님 때문에 빗장을 안 고쳤다. 고치면 그녀가 문으로 들어와 방값을 낸다.

## 1. 시간: 하루가 아니라 '며칠'
- 한 바퀴 = 사흘(@daytick n:3). 방값·사술 성장은 날마다 셈해 사흘치가 한꺼번에 붙는다. 독·곪은 상처는 마감마다 두 칸.
- 밤 행동(검·운기·날품·쉼)은 며칠 밤치 — nmul=3 이 @fx 변화량을 세 배로(검술 캡 판정은 밤마다 따로).
- 낮 사건 두 번까지(85% + 40%), 밤 사건 55%. 이야기 마디는 한 바퀴에 셋까지 이어진다(chain). 소아·사건 비트 주사위 확률 상향.
- 날짜 마디(D10·D18 …)는 '지났으면' 판정(ms_d*).
- 비무판: 이긴 밤은 "한 판 더"(세 판까지, 지거나 체력 절반 아래면 멈춤). 판마다 서열 폭을 키웠다(0.20~0.38, 뒷골목 0.11~0.22).
- 날품 삯 3~4(×3). 굶주림은 날마다 체력 −1.

- 상태줄의 'N일째' 삭제. 독·상처·빚 표시도 날수 대신 정도("번진다", "곧 독촉").

## 5. 부족한 것 채우기
- 진엔딩 길잡이: 합벽 검보 서신 끝 한 줄("산문은 혈쇄문의 사슬을 끊은 자에게만… 검보를 품은 자라면 서열은 서른 안이면 족하다") + 실제 조건(검보가 있으면 교주전 서열 30).
- 첫 회귀 안내: 무엇이 남는지(전생의 앎 → 보랏빛 선택지, 깨달음 → 다음 몸).
- ☰ 메뉴 '읽은 글 넘기기'(처음 보는 글·선택지에서 멈춤).
- 자동 기록(MolakAutoSave): 입력 대기 순간 90초마다 + 앱이 뒤로 갈 때, '— 기록했다'. 타이틀 '이어하기'는 가장 최근 기록으로 곧장.
- 환경 설정 → 제작 정보: 엔진, 생성형 AI 그림 고지, 글꼴 라이선스, 플레이 기록 파일 경로.
- 플레이 기록 파일: 생마다 한 줄(persistentDataPath/molak_playlog.csv), 기기 밖으로 보내지 않음.
- 출시 준비 묶음: RELEASE_PREP.md(상점 소개문·AI 고지·개인정보 처리방침·등급·지인 시험 안내).
