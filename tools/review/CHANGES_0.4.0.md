# 몰락검신 0.4.0 — 바뀐 것과 남은 것

**빌드(2026-11-10)**: 안드로이드 `몰락검신_v0.4.0.apk`(코드 25) · PC `몰락검신_v0.4.0_PC.zip`(윈도우 64비트, MolakBuild.Windows) — 둘 다 드라이브 Build_Apk. 빌드 전 소크 v26 9생: 소아의 검 2 · 사술 폭주 · 탈진 · 성사 · 등극 · 교주전 · 아사 · 원수 각 1(일반 비무 0). PC 빌드 뒤 에디터 대상이 StandaloneWindows64로 바뀌어 있음.

0.3.4 로드맵(ROADMAP_0.3.4.md)을 거의 다 소화하고, 사용자 요청 세 가지(세력의 특색, 루트 힌트를 숨기지 않기, 타이틀 재설계)를 더했다. 세력 설정은 FACTIONS.md, 인물 설계는 CHARACTERS.md에 있다.

## 1. 세력 (FACTIONS.md)
- **연표 고정**: 삼십 년 전 혈천교 토벌 → 십 년 전 혈마교 출세·무림맹 붕괴·적운 멸문 → 남궁 귀순 → 일 년 전 청운 멸문(맹의 원군은 남궁의 수레를 지키느라 오지 않음).
- **7일 서열각 감찰사(B7)**: 무명 쇠패 받기 / 쥐눈이 장을 통해 죽은 표사의 이름으로 받기(별 매듭 = 맹 연락책의 패) / 거절(개방 +1). 쇠패가 있으면 교도와의 시비에서 "패를 찬 자는 서열각의 것" 선택지.
- **무림맹 백리휘**: E_Maeng1(운주 뒤) → E_Maeng2(폐사찰 일곱, 그 밤의 수레 고백, 맹을 교에 팔기 → 원수) → E_Maeng3(맹의 저울 / 재건 엔딩 / 혈천진 동행). 야습에 원군: 신의 3↑ 제때, 아니면 반 시진 늦게(다음 생 앎).
- **남궁현**: 운주 심판석 → E_Namgung 하극상 비무(비치명, 첫 수 앎) → 측문(교주전 +1).
- **개방**: 프롤로그 그릇 매듭 → E_Gaebang1 매듭 신호 → E_Gaebang2 교의 쌀 → 39일(야습 사흘 전) 매듭 셋 → 혈천진 거지 샛길.
- **하오문**: E_Hao 다락의 노파와 손가락 문규. 쥐눈이 장의 배신 E_JangSell(15~18일, 딸이 징세 명부의 담보) / 끌려간 장 E_JangTaken. 다음 생: 열하루째 밤에 이유를 묻거나 딸 이야기를 먼저 꺼내 막는다.
- **녹림·독아단·혈쇄문·암향루·장풍표국·당가·관아**: 기존 장면에 그 집단 사람의 대사로 규율과 표식을 넣었다.
- **평판** rep_maeng / rep_gae / rep_heuk(이번 생). **강호록** 탭(세력 14, 그들이 한 말, 이번 생 신의).

## 2. 인물 아크
- **곽산**: 독 바른 창(dsitforce 4) → 아내 약값 → 할멈에게 잇기 / 약값 대신 / 폭로(이레 뒤 아내 사망, 원수 가능). 동행 보정: 혈쇄문 +1.5, 혈랑대 정예 +1.
- **백초 할멈(당가 방계)**: 교에 독을 대는 까닭 → 꾸러미 바꿔치기(호치 +2, 견아 +1.5) → 보름 뒤 약방이 탐(사망 경로). 다음 생: 교납 장부 무게 칸까지 바꿔 막는다. 약방이 탄 생은 향 가게 해약(14냥)만 남는다.
- **용개(녹림)**: 누이와 조카 때문에 길을 판다 → 매복(독) → 다음 생 먼저 말해 누이를 구한다(호치 +1.5).
- **원수 장부 · 생을 넘어**: 벤 자 / 나 때문에 죽은 자 / 살린 자를 회차마다 누적(MolakLedger).
- 죽은 인물의 흔적: 할멈(다음 생 첫 만남), 곽산의 아내(운주), 백리휘.

## 3. 회귀의 앎 (전생의 앎 37종)

## 4. 반복 변주
- **회차 테마**(첫 생은 맑음, 이후 4/5 확률, 직전과 다름): 장마(개울·빗속 비무) / 역병(약·장례↑, 장터↓, 기침) / 징세 강화(은자 −10, 징세 사건↑) / 늑대가 이르다(야습 38일, 추적↑). 회귀 아침에 한 줄로 예고, 며칠마다 테마 아침.
- **비무 형편 12종**: +등불 하나의 밤(물러서기 불가, 살기 +) · 맹인 검객(정면 −2, 받아치기 +2) · 아이를 업은 여검객(이기면 보내기만, 은인 확정) · 술 취한 고수(승산 표시가 틀림) · 교 감찰관 앞(이기면 수배, 지면 서열 밀림).
- **고정 비트 변주 13곳**(도입 3종 + 회귀 한 줄): 장·소아 수련·운주·명성·출정·사당·사슬·사냥 1·2·검은 산·포박·진실 1·3.
- **일상 행동 갈래**: 날품(떼인 삯 / 창고지기의 징세 귀띔 / 깔린 어깨) · 검(소아의 훈수 / 날이 나감) · 운기(주화의 문턱 / 한 뼘의 깨달음) · 쉼(지난 생의 꿈 / 데워 둔 국밥).
- **회귀 상점**: 이번 생의 채비(인연 1 · 물건 1, 생마다) · 몸이 먼저 기억한다(사흘째 칼 한 번 되묻기, 12).
- 첫 색 인장 때 범례 한 번, 첫 패배에 "목은 붙어 있다" 안내.

## 6. 타이틀
- 수면 위의 검객과 붉은 달, 달을 감싼 원상(처음 뜰 때 거꾸로 감기며 멈춘다).
- 버튼은 마른 붓 획 네 개(다시 그 아침으로 · 이어하기 · 말로록 · 환경 설정, 첫 획은 인주색), 손가락 눌림 표시. 나가기 버튼 없음.
- 말로록·전생의 앎·강호록·원수 장부 목록은 손가락 드래그 + 관성 스크롤.
- 겪은 일에 따라 더해지는 것: 생마다 등불 · 소아(동행/원행, 그 밤을 겪었으면 반투명) · 먼 물가의 사형(진백의 진실) · 흰 상복 셋(원수) · 물에 꽂힌 검(입마) · 등 뒤의 노인(성사) · 금 간 달(교주를 벤 결말) · 새벽 해와 금빛 원상(합벽).
