# 나니노벨 없이 — 자체 실행기로 옮기는 준비 (0.4.96, 2026-11-22)

> 언메이커(2026-11-22): 「이후로 대사나 이미지 찐빠가 또 나오면, 지금 구성을 나니노벨 없이 완전히 고치는 식으로 가 보자. 준비는 해 놔.」
> **착수 조건:** 0.4.95 이후 대사 흐름·그림 맞춤에서 같은 갈래의 결함이 또 나오면 이 문서대로 시작한다. 그 전까지는 준비만 한다.

## 1. 왜 갈아엎을 만한가
지금의 대사·그림 결함은 거의 다 **나니노벨의 인쇄기(글 찍기)·대기·선택지 위에 우리가 덧댄 보정층**에서 생긴다.
- 나니노벨은 「한 줄 찍고 → 누름 대기 → 다음 명령」 단위로 돈다. 몰락검신은 「한 쪽(여러 단락) + 그 쪽의 그림」 단위로 읽힌다.
- 그 차이를 메우려고 MolakFlow(쪽 나눔·대기 조절·FlipGate), MolakScroll(극장판 글 칸·선택지 요약), MolakArt(그림을 글과 맞춰 올리기), MolakPageBack(지난 쪽), MolakStoryAuto(선택지 숨김)가 나니노벨의 실행 흐름을 밖에서 붙잡고 있다.
- 결함이 나온 자리: 그림이 글보다 먼저(0.4.95), 소제목 뒤 잔상(0.4.96), 선택지가 뜰 때 본문이 사라졌다 돌아오는 잔상(0.4.85·0.4.91), 쪽 가운데서 멈춤(0.4.64), 이야기 모드에서 고른 말이 안 보임(0.4.94). 모두 「나니노벨이 이미 다음 명령을 실행했는데 화면은 아직 앞 쪽」인 틈이다.
- 자체 실행기는 **쪽을 먼저 다 만들고(글·그림·효과를 한 묶음으로) 그다음 화면에 그린다.** 그림과 글이 같은 묶음이라 어긋날 수 없다.

## 2. 대본은 그대로 쓴다 — 0단계 확인 끝
`python3 tools/engine/nani_ir.py` 가 대본 25개, 28,563줄(글 11,778 · 명령 12,072 · 선택지 1,360 · 라벨 3,353)을 **모르는 문법 0**으로 읽는다.
- 쓰는 문법이 작다: 명령 42종, 조건·식의 연산은 `&& || == != >= <= < > + - * / !`, 함수는 `random(a,b)` 하나, 본문 속 `{변수}` 316곳, 나니노벨 인라인 명령(`[i]` 등)은 없다.
- 그래서 `.nani` 파일과 쓰는 법(STORY_SESSION.md)은 바꾸지 않는다. vgen·static_check·story_picks·audit 도구도 그대로 쓴다.
- 새 명령·인자를 만들면 `tools/engine/nani_ir.py` 의 KNOWN 표에도 적는다(합계 0 유지).

## 4. 설계 — 쪽이 단위다
```
대본(.nani) ─ 파서 ─▶ IR(줄 목록·라벨 표)
                    │
             MolakRunner ── 명령 표(@set @goto @fx @art @chapter …)
                    │   다음 '멈출 자리'까지 미리 실행: 글이 쪽을 넘치거나 · 선택지 · @page/@chapter/장면 바뀜 · 효과(@black @turn @risk @duel …)
                    ▼
               쪽 묶음 { 단락들, 이 쪽의 그림(장면·인물·곁), 곡, 효과 큐, 능력치 알림 }
                    │
             MolakPage(화면) ── 그림을 올리고 → 글을 드러내고 → 누름/자동 → 다음 묶음
```
- **그림·곡은 쪽 묶음에 들어 있다.** 화면이 새 쪽을 그릴 때 함께 바뀐다. 「그림 먼저」 「곡 먼저」 「잔상」이 생길 틈이 없다.
- 효과(@vfx·@black·@turn·인장·비무)는 묶음 사이의 순서 있는 단계다. 효과가 끝나야 다음 쪽을 그린다.
- 지난 쪽 보기·이야기 모드 읽기는 쪽 묶음 목록을 그대로 다시 그리면 된다(그림 포함).
- 이야기 모드 자동 고르기는 선택지 단계에서 화면 대신 기준표가 고른다(지금 MolakStoryAuto 의 점수 그대로).
- 넘기기·빨리·자동은 「쪽을 얼마나 오래 보여 주느냐」의 차이일 뿐이다.

## 5. 단계
| 단계 | 할 일 | 끝났는지 보는 법 |
|---|---|---|
| 0 준비 | 의존 면 조사 · 대본 전수 파싱(nani_ir.py) · 이 문서 | **끝(0.4.96)** |
| 1 실행기 | C# 파서·식 평가기·변수(MolakStats 저장소 교체)·명령 표·gosub 더미. 화면 없이 대본을 끝까지 도는 머리 없는 봇 | 같은 선택으로 나니노벨 판과 변수·끝(엔딩)이 똑같다(봇 r 시험 대조) |
| 2 화면 | MolakPage(쪽 그리기·드러내기·누름)·선택지 카드·극장판/그림 화면 배치 — MolakScroll·MolakTheme 의 배치 값을 옮긴다 | 빨리·보통·자동·넘기기에서 MolakSyncCheck 이른 그림 0, 쪽 찍힘 사진 대조 |
| 3 저장 | 이어하기·불러오기·자동 저장, 지난 판 저장은 버리거나 변수만 옮긴다 | 저장→불러오기 뒤 같은 쪽·같은 그림 |
| 4 걷어 내기 | 나니노벨 패키지·프리팹·Command 클래스 제거, 빌드 전처리 제거 | 안드로이드 빌드·소크 통과 |

- 1~2단계 동안 나니노벨 판은 그대로 둔다(같은 대본을 두 실행기가 읽는다). 3단계에서 갈아탄다.
- 저장 호환: 테스터 기기의 이어하기는 깨질 수 있다 — 갈아타는 판에서 한 번 알린다(전역 앎 g_ 는 옮긴다).

## 6. 지켜야 할 것(지금 동작 그대로)
- 쪽 넘김 규칙(MolakFlow): 대사는 앞뒤 빈 줄, 단락이 길면 숨 쉴 빈 줄, 선택지 뒤 첫 글은 새 쪽, 이음 문장(bridge)은 쪽을 넘기지 않는다, 그림 화면은 대사마다 제 쪽.
- 지난 생 줄(@deja + {dejapre}), 승부수 주석(〔검술+2〕 → 카드 아래 승산), 잠긴 선택지(lock:), 보랏빛 앎, 주인공 대사 오른쪽.
- 극장판 기본, 마디 이름 덮개, 먹 화면, 판이 바뀌는 날 카드, 인장, 기연 카드, 비무(MolakDuelX)·수련.
- 이야기 모드(편마다 진엔딩, 지난 쪽 처음까지), 소크 봇(MolakEndTester)·점검 도구(MolakSyncCheck·static_check).
