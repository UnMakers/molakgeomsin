# 몰락검신 — 세션 사이 주고받기

이야기 세션과 개발 세션이 서로에게 넘길 일을 여기에 적는다. 언메이커가 말을 옮기지 않아도 되게 하려는 것이다.

- 세션을 열면 `git pull` 뒤 이 파일부터 읽고, **자기 쪽으로 온 열린 항목(☐)** 부터 처리한다.
- 처리하면 ☐ → ☑ 로 바꾸고 한 줄로 결과를 붙인다(커밋 번호). 다 끝난 항목은 다음 사람이 「지난 것」으로 옮긴다.
- 넘길 때는 무엇을, 어디(대본:줄·커밋 범위)를, 끝나면 무엇을 해 달라는지 적는다. 자세한 건 따로 문서를 두고 이름만 건다.
- 고친 뒤 바로 커밋·푸시한다. 두 세션이 같은 파일을 고칠 수 있으니 커밋 전에 다시 `git pull`.
- 빌드는 언메이커가 하라고 할 때만 한다(개발 세션).
