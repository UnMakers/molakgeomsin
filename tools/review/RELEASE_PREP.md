# 몰락검신 — 출시 준비 묶음 (0.4.22 기준으로 갱신, 2026-11-12)

게임 안에서 채울 수 있는 것은 넣었다. 여기에는 게임 밖에서 준비할 것과 그대로 쓸 수 있는 초안을 모았다.

## 0. 지금 상태 한눈에
- 본문 약 18만 6천 자, 이야기 마디 90여 개, 낮·밤 사건 140여 개, 말로 34종(진엔딩 합벽 포함).
- 희생 자리 여섯(연·사슬 창고·야습·교주전·곽산의 생사결·청묘의 산문), 종장 앞 「떠나기 전 밤」과 「북행」.
- 회차 편의: 읽은 글 넘기기, 「기억대로 흘려보낸다」(두 번째 생부터 아흐레 건너뛰기), 생을 넘는 사건 기억.
- 빌드: 안드로이드 IL2CPP, ARMv7·ARM64, 패키지 `com.unmakers.molakgeomsin`, 최소 API 25, 타깃 API 'Auto'(설치된 최고 수준).

## 1. 구글 플레이 출시에 꼭 필요한 것 (막히는 순서대로)
1. **개발자 계정**(언메이커님): 개인 계정이면 프로덕션 공개 전에 **비공개 테스트 12명 이상 × 14일 연속**이 필요하다(2023년 11월 이후 만든 개인 계정 규정). 지인 시험과 겸하면 된다.
2. **업로드 키(키스토어)**(언메이커님): 지금은 디버그 키로 서명된 APK다. 유니티 `Project Settings → Player → Publishing Settings → Keystore Manager`에서 새 키스토어를 직접 만들고, 비밀번호는 본인만 보관한다. 키를 잃으면 업데이트를 못 올린다(플레이 앱 서명을 켜 두면 업로드 키는 재발급 가능).
3. **AAB 빌드**(제 쪽): 플레이 스토어는 APK가 아니라 AAB를 받는다. `MolakBuild`에 AAB 옵션을 더하고, 키스토어가 생기면 그 키로 서명한다.
4. **타깃 API 36**(제 쪽): 2026년 8월 31일부터 새 앱과 업데이트는 Android 16(API 36) 이상을 타깃해야 한다. 'Auto'가 36으로 잡히는지 빌드 로그로 확인하고, 아니면 36으로 고정한다.
5. **개인정보 처리방침 URL**(언메이커님): 아래 3절 초안을 노션·깃허브 페이지 한 장에 올린다.
6. **콘텐츠 등급(IARC)·데이터 보안 설문**: 수집 없음, 네트워크 권한 없음으로 답한다. 4절 참고.
7. **상점 그림**(제 쪽): 아이콘 512², 피처 그래픽 1024×500, 세로 스크린샷 4~8장(1080×1920).

## 2. 상점 소개문 초안
**한 줄**
> 죽어야 배운다. 몰락한 검객이 같은 아침으로 되돌아오며, 사문을 무너뜨린 교(敎)의 밑바닥을 한 겹씩 벗긴다.

**짧은 소개(80자 안팎)**
> 혈마교에 사문을 잃은 청운의 막내. 죽을 때마다 그날 아침으로 돌아온다. 남들은 잊고 그만 기억한다. 서른네 가지 말로 끝에 하나뿐인 합벽(合璧)을 찾아라.

**긴 소개**
> 청운검파의 막내 제자는 일 년을 누워 있다가 눈을 뜬다. 가슴에는 사술의 문양, 손에는 은자 서른 냥.
> 그가 죽으면 시간이 되감긴다. 뽑히지 않은 칼이 칼집으로 돌아가고, 흘린 피가 상처 속으로 기어든다. 되감기지 않는 것은 단 하나, 앎이다.
>
> · 회귀할수록 열리는 선택지 — 지난 생에 본 것, 들은 것이 보랏빛 인장을 단 새 선택지가 된다.
> · 너는 잊고, 나는 기억한다 — 누군가 죽을 자리에 대신 설 수 있다. 다음 생의 그 사람은 아무것도 모른다.
> · 서로 얽힌 사람들 — 지붕 위의 외눈 쌍검, 향 파는 여인, 머리를 깎은 사저, 셈이 늘 틀리는 객잔 주인. 같은 자리, 같은 필요, 같은 밤으로 서로 만난다.
> · 서른네 가지 말로 — 비무에 져서 죽는 것보다, 선택의 대가로 무너지는 결말이 더 많다.
> · 먹의 화첩 — 수묵 삽화, 세로 화면, 손가락 하나로 넘기는 책장.
>
> 몇 번을 죽어도 좋다. 같은 자리에서 두 번 죽지만 마라.

**태그 후보**: 무협, 회귀, 로그라이트, 텍스트 어드벤처, 비주얼 노벨, 선택지, 다회차, 멀티 엔딩

## 3. 개인정보 처리방침 초안 (수집 없음)
> 「몰락검신」은 이용자의 개인정보를 수집하지 않습니다.

> 게임은 네트워크 권한을 사용하지 않습니다. *(광고·분석·클라우드 저장을 붙이면 이 문서를 고쳐야 한다)*
